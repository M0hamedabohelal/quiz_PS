# CS413 — Problem Solving & Decision Making Interactive Quiz App 🧠

تطبيق ويب تفاعلي وشامل لمادة **Problem Solving and Decision Making (CS413)** يغطي بنك الأسئلة المكون من **50 سؤال اختيار من متعدد (MCQs)** لمحاضرات (Lectures 1 & 2) مع الشرح المفصل لكل إجابة وموضعها الدقيق في السلايدات ومصدر الـ PDF.

---

## 🌟 مميزات التطبيق

1. **ثلاثة أوضاع للمذاكرة والاختبار**:
   - **وضع التدريب والشرح الفوري (Study Mode):** يوضح صحة الإجابة فور الضغط عليها، مع إظهار سبب الإجابة بالتفصيل (**Why?**) ومصدرها الدقيق من السلايدات (**Source: PDF p. X — Slide Y**).
   - **وضع الاختبار التجريبي (Exam Mode):** محاكاة واقعية للاختبار بوقت محدد (مؤقت 45 دقيقة)، إمكانية الانتقال وتحديد الأسئلة للمراجعة، وتصحيح نهائي بنسبة مئوية ورسم بياني مع تصنيف التقدير (A+, A, B...).
   - **استعراض كافة الأسئلة (Review All Mode):** عرض كافة الـ 50 سؤالاً دفعة واحدة مع خاصية البحث الفوري والفلترة حسب المحاضرة (Lecture 1 / Lecture 2).

2. **فهرس الأسئلة التفاعلي (Question Navigator - 50 Buttons)**:
   - لوحة جانبية بـ 50 زر ملونة توضح: الإجابات الصحيحة (أخضر)، الخاطئة (أحمر)، الأسئلة المحددة للمراجعة 🚩، والسؤال الحالي.
   - إمكانية الفلترة السريعة للتركيز على الأسئلة الخاطئة فقط.

3. **مؤثرات صوتية ومرئية تفاعلية**:
   - مؤثرات صوتية نظيفة (Web Audio API بدون ملفات خارجية ثقيلة).
   - احتفالية صوتية عند الحصول على درجة امتياز.

4. **الوضع الليلي والفاتح (Dark / Light Mode)**:
   - تبديل سهل ومريح للعين مع حفظ التفضيلات محلياً.

5. **اختصارات لوحة المفاتيح**:
   - اختيار الأجوبة عبر المفاتيح: `A` / `B` / `C` / `D` أو `1` / `2` / `3` / `4`.
   - التنقل بين الأسئلة عبر الأسهم `←` و `→`.
   - وضع علامة مراجعة عبر زر `F`.

6. **يعمل بدون إنترنت (100% Offline Capable)**:
   - لا يتطلب أي سيرفر أو تثبيت حزم، يكفي فتح ملف `index.html` في أي متصفح!

## 🚀 تشغيل الموقع عبر GitHub Pages (رابط مباشر)

لتشغيل التطبيق كرابط مباشر أونلاين:
1. اذهب إلى إعدادات المستودع على GitHub: **Settings**.
2. من القائمة الجانبية اختر **Pages**.
3. تحت قسم **Build and deployment** / **Source**:
   - اختر **Deploy from a branch**.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
4. خلال دقيقة ستحصل على رابط مباشر مثل:
   `https://m0hamedabohelal.github.io/quiz_PS/`

## 📚 محتوى الأسئلة والمحاضرات

- **Lecture 1 (Questions 1 - 25):**
  - Problem Statement definition & key qualities (Simple, Specific, Objective).
  - The 5 Ws framework (Who, What, Where, When, Why).
  - Focus clarification & communication enhancement.
  - Problem-solving cycle (Define → Diagnose → Identify/Implement → Sustain).
  - Gemba review, data collection (qualitative & quantitative).
  - Root Cause Analysis (RCA) & 5 Whys.
  - Generating alternatives, hybrid solutions, contingency planning, and implementation barriers.

- **Lecture 2 (Questions 26 - 50):**
  - Classical & Traditional Planning (Knowledge-intensive, state-space search).
  - Applications in manufacturing and robotics.
  - Blocks-world domain: operators (`pickup`, `putdown`, `stack`, `unstack`), predicates (`clear`, `gripping`, `on`, `ontable`).
  - STRIPS system: Preconditions (P), Add list (A), Delete list (D).
  - Decision-making processes, skills (Adaptability, Risk Assessment), and the 7-step decision flow.
